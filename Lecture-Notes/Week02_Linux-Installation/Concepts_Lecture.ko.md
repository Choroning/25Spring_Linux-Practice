## 1. Linux 기초

### 1.1 Linux 커널과 응용 프로그램

Linux 시스템은 커널과 응용 프로그램이라는 두 가지 주요 구성 요소로 이루어지며, 그 아래에 하드웨어가 있다. 응용 프로그램이 실행되는 영역을 **사용자 공간(user space)**, 커널이 실행되는 영역을 **커널 공간(kernel space)** 이라 한다.

```text
+---------------------------+
|    응용 프로그램          |  <-- 텍스트 편집기, 컴파일러, 웹 서버
|  (User Space)             |
+---------------------------+
|       Linux 커널          |  <-- 프로세스 관리, 파일 시스템, 메모리, 장치
|  (Kernel Space)           |
+---------------------------+
|        하드웨어           |  <-- CPU, RAM, 디스크, NIC
+---------------------------+
```

*그림 1. Linux 커널과 응용 프로그램, 하드웨어의 관계*

- **커널:** 프로세스 스케줄링, 메모리 관리, 파일 시스템 운영, 장치 입출력을 관리한다.
- **응용 프로그램:** 커널 위에서 실행되며 사용자가 직접 사용하는 프로그램이다. 사용자의 명령을 해석하는 셸은 커널과 응용 프로그램 사이에 놓인다(1주차 5절).
- 2025년 3월 기준 최신 커널 버전은 **6.13.5**이다(https://kernel.org).

### 1.2 Linux 특징

| 특징 | 설명 |
|------|------|
| 오픈소스 | GPL 라이선스에 따라 소스 코드를 자유롭게 이용 가능 |
| Unix 호환 | Unix와 높은 호환성을 유지하며 POSIX 표준을 대부분 준수 |
| 다중 사용자 | 여러 사용자가 동시에 시스템 사용 가능 |
| 다중 작업 | 여러 프로세스를 동시에 실행 |
| 안정성 | 재부팅 없이 수년간 운영 가능 |
| 보안 | 내장된 접근 제어, SELinux, AppArmor |
| 서버 운영체제 | 서버용 운영체제로 많이 사용 |
| GUI 지원 | GNOME, KDE, XFCE 데스크톱 환경 |

*표 1. Linux의 주요 특징*

## 2. 실습 환경 설정

### 2.1 가상 머신 설치

실습에는 VMware Workstation(Player 또는 Pro)을 사용하여 가상 머신을 생성한다. 가상 머신의 개념은 1주차 7절에서 다룬다.

**다운로드:** https://www.vmware.com/ (2025년 3월 기준 버전 17.6.2)

가상 머신은 다음 순서로 만든다.

1. VMware Workstation Player를 실행하고 Create a New Virtual Machine을 선택한다.
2. 게스트 OS 설치 방법으로 운영체제를 나중에 설치하는 항목(I will install the operating system later)을 골라 빈 하드디스크만 먼저 만들고, 게스트 OS 종류로 Linux를 선택한다.
3. 가상 머신의 이름과 디스크 파일의 위치를 지정한다.
4. 디스크 크기(20GB)와 저장 방식(Split virtual disk into multiple files)을 지정한다.

### 2.2 Ubuntu를 위한 VM 구성

| 매개변수 | 권장 값 |
|----------|---------|
| 메모리 | 4 GB |
| 디스크 | 20 GB (동적 할당, 여러 파일로 분할 저장) |
| CPU | 2코어 |
| 네트워크 | NAT 모드 |
| 게스트 OS | Ubuntu 24.04 LTS (Desktop, Server) |

*표 2. Ubuntu 가상 머신의 권장 구성*

### 2.3 VMware 편의 기능

```text
# 주요 단축키
Ctrl + Alt         # VM에서 호스트로 마우스 해제
Ctrl + Alt + Enter  # 전체 화면 모드 전환
```

- **Clone(복제):** 병렬 테스트를 위해 VM을 복제한다.
- **Suspend(일시 중지):** 현재 VM 상태를 저장하고 나중에 재개한다.
- **Snapshot(스냅샷):** 안전한 실험을 위한 복원 지점을 만든다.

## 3. Ubuntu Linux 설치

### 3.1 Ubuntu 다운로드

- **Desktop** (GUI 포함): GNOME 데스크톱을 포함하며 초보자에게 적합하다.
- **Server** (CLI만): 가벼우며 운영 서버용으로 쓴다.

다운로드: https://ubuntu.com/download

### 3.2 설치 단계

1. VMware에서 새 가상 머신을 생성한다.
2. Ubuntu ISO 이미지를 가상 머신의 CD/DVD 장치에 지정한다.
3. VM 설정(메모리, 디스크, 네트워크)을 구성한다.
4. ISO로 부팅하고 설치 프로그램을 따라 진행한다.
5. 호스트 이름(컴퓨터 이름), 사용자 이름, 비밀번호를 설정한다.
6. 설치가 끝나면 재부팅한다.

실습에서는 설치 프로그램의 각 단계에서 다음과 같이 선택한다.

| 설치 단계 | 선택 |
|-----------|------|
| 언어와 설치 방법 | 한국어, Ubuntu 설치 |
| 키보드 레이아웃 | Korean |
| 설치할 소프트웨어와 업데이트 | 최소 설치, 업데이트 다운로드 체크 해제 |
| 설치 형식 | 디스크를 지우고 Ubuntu 설치 |
| 시간대 | Seoul |
| 사용자 계정 | 사용자 이름 user1(암호 설정), 컴퓨터 이름 myubuntu |

*표 3. 실습에서 사용하는 Ubuntu 설치 선택 항목*

> **주의:** 가상 머신 안에서 디스크를 지우고 설치하면 가상 디스크만 지워지지만, 실제 PC에서 같은 항목을 고르면 기존 운영체제와 데이터가 모두 지워진다.

설치가 끝나고 재부팅하면 로그인 화면이 나타나며, 로그인한 뒤 초기 설정 항목을 선택한다.

### 3.3 설치 후 설정

```bash
# 패키지 목록 업데이트 및 설치된 패키지 업그레이드
sudo apt update && sudo apt upgrade -y

# 필수 빌드 도구 설치
sudo apt install -y build-essential

# VM 통합을 위한 VMware Tools 설치
sudo apt install -y open-vm-tools open-vm-tools-desktop

# Ubuntu 버전 확인
lsb_release -a

# 커널 버전 확인
uname -r
```

## 4. Linux 데스크톱 환경

### 4.1 GNOME 데스크톱

Ubuntu는 기본적으로 **GNOME** 데스크톱 환경을 사용하며, 주요 구성 요소는 다음과 같다.

- **Activities 개요(현재 활동):** 화면 왼쪽 위에서 열며, 자주 쓰는 프로그램의 아이콘과 현재 실행 중인 프로그램, 작업 공간을 보여 준다.
- **독(dock):** 화면 왼쪽에 Firefox, Thunderbird, 파일, 소프트웨어, 도움말, 휴지통 같은 프로그램의 아이콘을 늘어놓는다.
- **응용 프로그램 메뉴:** 독 맨 아래의 프로그램 표시 버튼으로 열며, 설치된 프로그램을 실행한다.
- **날짜와 시간:** 화면 위쪽 가운데에서 날짜, 시간, 알림을 관리한다.
- **시스템 트레이:** 화면 오른쪽 위에서 소리, 네트워크, 블루투스, 전원(컴퓨터 끄기, 로그아웃)을 설정한다.
- **파일 관리자 (Nautilus):** GUI로 파일을 관리한다.

### 4.2 터미널 에뮬레이터

터미널은 명령을 입력하여 시스템을 다루는 창으로, Linux 관리에서 가장 중요한 도구이다. 프로그램 표시에서 터미널을 골라 열거나 다음 단축키로 연다.

```text
# 터미널 열기
Ctrl + Alt + T    # Ubuntu GNOME에서의 키보드 단축키

# 터미널 프롬프트 형식
username@hostname:~$    # 일반 사용자
root@hostname:~#        # Root 사용자
```

**프롬프트(prompt)** 는 셸이 사용자의 명령 입력을 기다리고 있음을 나타내는 표시이다. 프롬프트의 `~`는 **홈 디렉터리(home directory)** 를 뜻하며, 홈 디렉터리는 사용자 계정의 기본 디렉터리로서 터미널을 열면 처음 위치하는 곳이다. 현재 위치는 `pwd` 명령으로 확인한다. 터미널은 창의 닫기 버튼을 누르거나, `exit`를 입력하거나, 빈 명령줄에서 `Ctrl + D`를 눌러 닫는다.

> **핵심:** `$` 프롬프트는 일반 사용자를, `#`은 root(슈퍼유저)를 나타낸다.

## 5. 기본 Linux 명령어

### 5.1 명령의 구조

Linux 명령은 `명령 [옵션] [인자]` 형식으로 입력한다. 대괄호는 생략할 수 있다는 뜻이다.

- **명령:** 사용자가 실행하려는 프로그램의 이름이며, `date`, `man`, `ls`, `cp`, `mv` 등 수백 가지가 있다.
- **옵션:** 명령의 세부 기능을 선택한다. `-`나 `--`로 시작하며 영문 소문자나 대문자로 이루어진다. 어떤 옵션이 있고 무슨 기능을 하는지는 명령마다 다르므로 해당 명령의 사용법을 참조한다.
- **인자:** 명령에 전달하는 값으로, 주로 파일 이름이나 디렉터리 이름이다. 인자가 없는 명령도 있고, 필요한 인자도 명령마다 다르다.

```bash
ls              # 명령만 사용: 현재 디렉터리의 내용 출력
ls -a           # 명령과 옵션: 숨김 파일까지 출력
ls /tmp         # 명령과 인자: /tmp 디렉터리의 내용 출력
ls -a /tmp      # 명령, 옵션, 인자: /tmp의 숨김 파일까지 출력
```

### 5.2 시스템 정보 명령어

```bash
# 현재 날짜 및 시간 표시
date
# 출력: Fri Mar 21 14:30:00 KST 2025

# 달력 표시
cal
cal 2025           # 연간 달력

# 로그인된 사용자 표시
who
w                   # 더 자세한 정보

# 시스템 가동 시간 표시
uptime

# 호스트 이름 표시
hostname

# 커널 정보 표시
uname -a
```

한국어 환경에서는 `date`가 `2025. 03. 21. (금) 14:30:00 KST`처럼 출력된다. 화면을 지우려면 `clear`를 입력한다.

### 5.3 사용자 명령어

```bash
# 현재 사용자 이름 표시
whoami

# 사용자 전환
su - username       # 다른 사용자로 전환
su -                # root로 전환

# 슈퍼유저로 실행
sudo command        # 단일 명령어를 root로 실행
sudo -i             # root 셸 열기
```

`passwd`는 사용자 계정의 비밀번호를 바꾼다. 인자 없이 실행하면 현재 비밀번호를 먼저 묻고, 새 비밀번호를 두 번 입력받아 바꾼다.

### 5.4 도움말 및 매뉴얼 페이지

```bash
# 명령어 매뉴얼 표시
man ls              # ls의 매뉴얼 페이지
man -k keyword      # 키워드로 매뉴얼 검색

# 간단한 도움말
ls --help           # 대부분의 명령어에 내장된 도움말
info ls             # GNU info 문서

# 명령어 유형 표시
type ls             # 명령어가 내장, 별칭, 외부인지 표시
which ls            # 명령어 바이너리의 경로 표시
```

매뉴얼 페이지는 NAME(명령의 간략한 설명), SYNOPSIS(사용법 요약), DESCRIPTION(자세한 설명) 같은 절로 나뉘며, `q`를 누르면 빠져나온다.

### 5.5 시스템 제어

```bash
# 시스템 종료
sudo shutdown -h now          # 즉시 종료
sudo shutdown -h +10          # 10분 후 종료
sudo poweroff                 # 대체 종료 명령어

# 시스템 재부팅
sudo shutdown -r now          # 즉시 재부팅
sudo reboot                   # 대체 재부팅 명령어

# 예약된 종료 취소
sudo shutdown -c
```

`shutdown`의 매뉴얼에 문서화된 시간 인자는 `hh:mm`(24시간제 시각), `+m`(지금부터 m분 뒤), `now`(즉시)의 세 가지 형식이다.

### 5.6 명령줄 편집 단축키

| 단축키 | 동작 |
|--------|------|
| `Backspace`, `Delete` | 커서 앞이나 커서 위치의 문자 삭제 |
| `Ctrl + A` | 줄의 시작으로 커서 이동 |
| `Ctrl + E` | 줄의 끝으로 커서 이동 |

## 6. 원격 접속 설정

### 6.1 SSH (Secure Shell)

**SSH(Secure Shell)** 는 네트워크를 통해 다른 컴퓨터에 암호화된 연결로 로그인하는 프로토콜이며, 기본 포트는 22이다. 접속을 받는 Ubuntu에는 SSH 서버를 설치한다.

```bash
# Ubuntu에 SSH 서버 설치
sudo apt install -y openssh-server

# SSH 서비스 상태 확인
sudo systemctl status ssh

# 부팅 시 SSH 자동 시작 설정
sudo systemctl enable ssh

# 다른 머신에서 접속
ssh username@ip_address
ssh -p 2222 username@ip_address    # 사용자 지정 포트
```

### 6.2 IP 주소 확인

```bash
# 네트워크 인터페이스 정보 표시
ip addr show
ip a                # 축약형

# 레거시 명령어
ifconfig            # 필요 시: sudo apt install net-tools
```

출력에서 `inet` 옆에 있는 주소가 그 인터페이스의 IPv4 주소이다. Ubuntu Desktop과 Server에서 각각 이 주소를 확인한 뒤, 호스트의 터미널(예: macOS의 터미널)에서 `ssh 사용자명@IP주소`를 실행하면 각 가상 머신에 접속할 수 있다.

> **[컴퓨터네트워크]** 컴퓨터네트워크에서 배우는 TCP/IP 계층으로 보면, SSH는 TCP 위에서 동작하는 응용 계층 프로토콜이다. IP 주소는 네트워크에서 목적지 호스트(여기서는 가상 머신)를 찾는 데 쓰이고, 포트 번호는 그 호스트 안에서 연결을 받을 프로세스를 가리킨다. 그래서 `ssh 사용자명@IP주소`는 IP 주소로 VM을 찾아 SSH 서버가 기다리는 기본 포트 22에 TCP 연결을 맺으며, 서버가 다른 포트를 쓰면 `-p`로 포트 번호를 지정한다.

## 7. 모범 사례

### 7.1 보안

- 사용자 계정에는 항상 강력한 비밀번호를 사용한다.

## 점검 문제

1. **명령의 구조:** `ls -a /tmp`에서 명령, 옵션, 인자를 각각 찾고, 이 명령이 출력하는 내용을 설명하라.

   <details>
   <summary>정답</summary>

   명령은 `ls`, 옵션은 `-a`, 인자는 `/tmp`이다. `ls`는 디렉터리의 내용을 출력하는 명령이고, 인자 `/tmp`가 대상 디렉터리를 지정하며, 옵션 `-a`가 `.`으로 시작하는 숨김 파일까지 출력하게 한다. 따라서 `/tmp` 디렉터리에 있는 모든 파일과 디렉터리를 숨김 파일을 포함하여 출력한다.

   </details>

2. **명령의 유형:** Ubuntu에서 `type cd`는 `cd is a shell builtin`을 출력하지만 `which cd`는 아무것도 출력하지 않는다. 그 이유를 설명하라.

   <details>
   <summary>정답</summary>

   `cd`는 별도의 실행 파일이 아니라 셸에 내장된 명령이다. `type`은 셸의 내장 명령, 별칭, 외부 명령을 모두 구분하여 알려 주지만, `which`는 PATH에 있는 디렉터리에서 실행 파일만 찾는다. `cd`라는 실행 파일이 없으므로 `which cd`는 아무것도 출력하지 않고 실패한다.

   </details>

3. **원격 접속 절차:** 호스트 PC의 터미널에서 VM에 설치한 Ubuntu에 SSH로 접속하려고 한다. Ubuntu 쪽에서 해야 할 일과 호스트에서 실행할 명령을 순서대로 쓰라.

   <details>
   <summary>정답</summary>

   Ubuntu에서 `sudo apt install -y openssh-server`로 SSH 서버를 설치하고, `sudo systemctl status ssh`로 서비스가 동작하는지 확인하며, 필요하면 `sudo systemctl enable ssh`로 부팅 시 자동으로 시작되게 한다. 이어서 `ip addr show`의 `inet` 항목에서 IP 주소를 확인한다. 마지막으로 호스트의 터미널에서 `ssh user1@IP주소`를 실행하고 user1의 비밀번호를 입력한다.

   </details>

4. **사용자 공간과 커널 공간:** 텍스트 편집기로 파일을 저장할 때 편집기와 커널이 각각 맡는 일을 그림 1의 계층에 따라 설명하라.

   <details>
   <summary>정답</summary>

   편집기는 사용자 공간에서 실행되는 응용 프로그램으로, 사용자가 입력한 내용을 메모리에 들고 있다가 커널에 파일에 쓰도록 요청한다. 커널은 커널 공간에서 그 요청을 받아 파일 시스템을 갱신하고, 장치 입출력으로 디스크(하드웨어)에 실제 데이터를 기록한다. 응용 프로그램은 하드웨어를 직접 다루지 않고 커널을 거친다.

   </details>
