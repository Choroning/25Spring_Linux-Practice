## 1. Linux 텍스트 편집기

### 1.1 편집기의 종류

Linux의 편집기는 그래픽 환경에서 쓰는 GUI 편집기와 터미널에서 쓰는 편집기로 나뉜다. 터미널 편집기는 다시 한 번에 한 줄씩 다루는 줄 편집기와 화면 전체를 다루는 화면 편집기로 나뉜다.

| 분류 | 편집기 | 설명 |
|------|--------|------|
| 줄 편집기 | `ed`, `ex`, `sed` | 한 번에 한 줄씩 편집한다. |
| 화면 편집기 | `vi`, `emacs` | 전체 화면에서 편집한다 (모달 / 모드리스). |
| GUI 편집기 | `gedit`, `kate` | 그래픽 인터페이스로 편집한다. |

*표 1. Linux 편집기의 분류*

### 1.2 모달 vs. 모드리스 편집기

- **모드형(모달) 편집기**는 입력 모드와 명령 모드를 구분한다. 입력 모드에서는 텍스트를 입력하고, 명령 모드에서는 텍스트를 수정, 삭제, 복사하거나 붙이는 편집 명령을 수행한다. vim이 대표적이다.
- **비모드형(모드리스) 편집기**는 모드 구분이 없다. 한글, 워드 같은 문서 편집기처럼 Alt, Ctrl, Shift 같은 특수 키와 다른 키를 함께 눌러 편집 명령을 수행한다. 터미널에서는 nano가 대표적이다.

| 기능 | 모달 (vi/vim) | 모드리스 (nano, notepad) |
|------|--------------|-------------------------|
| 입력 모드 | 텍스트 입력 | 텍스트 입력 |
| 복사 | `yy` (명령 모드) | `Ctrl+C` |
| 붙여넣기 | `p` (명령 모드) | `Ctrl+V` |
| 저장 | `:wq` 또는 `ZZ` | `Ctrl+S` |
| 모드 전환 | `i`, `a`, `o`, `Esc` | 해당 없음 |

*표 2. 모달 편집기와 모드리스 편집기의 조작 비교*

> **핵심:** `vim`은 `vi`의 업그레이드 버전(Vi IMproved)이다. 핵심 사용법은 동일하다.

> **참고:** 표 2의 모드리스 열에서 복사와 붙여넣기는 메모장(notepad) 같은 GUI 편집기의 단축키이다. 터미널의 nano는 1.3절처럼 단축키가 다르다.

### 1.3 nano 편집기

**nano**는 터미널에서 사용하는 모드리스 텍스트 편집기이다. vi와 달리 명령 모드와 마지막 줄 모드가 없고, 모든 명령을 Ctrl 또는 Alt와 다른 키를 함께 누르는 단축키로 입력한다. `nano a.txt`처럼 파일 이름을 주어 실행하면 그 파일을 열고, 커서는 방향키로 상하좌우로 옮긴다. 화면 아래쪽 도움말의 `^`는 Ctrl 키를 뜻한다.

| 단축키 | 기능 | 단축키 | 기능 |
|--------|------|--------|------|
| `Ctrl+G` | 도움말 | `Ctrl+X` | 종료 |
| `Ctrl+S` | 저장 | `Ctrl+O` | 파일 이름을 확인받고 저장 |
| `Ctrl+R` | 파일 읽어 오기 | `Ctrl+\` | 검색 및 바꾸기 |
| `Ctrl+K` | 현재 줄 잘라내기 | `Ctrl+U` | 붙여넣기 |
| `Ctrl+Y` | 이전 페이지 (Page Up) | `Ctrl+V` | 다음 페이지 (Page Down) |

*표 3. nano의 주요 단축키*

## 2. Vi 동작 모드

### 2.1 세 가지 모드

```text
                    i, I, a, A, o, O
    +-------------+  ──────────────>  +-------------+
    | 명령 모드   |                   |  입력 모드   |
    | (Normal)    |  <──────────────  | (Insert)     |
    +------+------+      Esc          +-------------+
           │
      : / ?│         Enter
           v           │
    +------+------+    │
    | 마지막 줄   |────┘
    | 모드 (Ex)   |
    +------+------+
           │
     :q :wq :q!
           v
    +-------------+
    |   Vi 종료   |
    +-------------+
```

*그림 1. vi의 세 가지 동작 모드와 모드 전환*

- **명령 모드 (Normal):** 키 입력을 명령으로 해석하여 커서 이동, 페이지 이동, 글자 삭제, 줄 삭제, 복사 등을 수행한다. vi를 시작하면 이 모드에서 시작한다.
- **입력 모드 (Insert):** 키 입력이 텍스트 내용으로 입력된다.
- **마지막 줄 모드 (Ex):** 화면 하단에서 `:`, `/`, `?` 뒤에 명령어를 입력하여 검색, 바꾸기, 저장, 종료 같은 특별한 명령을 처리한다.

### 2.2 모드 전환

- **명령 모드에서 입력 모드로:** `i`, `I`, `a`, `A`, `o`, `O` 중 하나를 누른다. 키마다 텍스트 입력이 시작되는 위치가 다르다(5.1절).
- **입력 모드에서 명령 모드로:** `Esc` 키를 누른다. 입력 모드에서 마지막 줄 모드로 바로 갈 수는 없으므로, 저장하거나 종료하려면 먼저 `Esc`로 명령 모드에 돌아와야 한다.
- **명령 모드에서 마지막 줄 모드로:** `:`, `/`, `?` 중 하나를 누르면 커서가 화면 맨 아래 줄로 이동한다.
- **마지막 줄 모드에서 명령 모드로:** 명령을 입력하고 `Enter`를 누르면 명령이 실행된 뒤 명령 모드로 돌아온다. 명령을 실행하지 않고 돌아오려면 `Esc`를 누른다.
- **vi 종료:** 마지막 줄 모드의 `:q`, `:q!`, `:wq`, `:wq!`로 종료하거나, 명령 모드에서 `ZZ`를 눌러 저장하고 종료한다.

`i`와 `a`의 차이는 커서가 있는 글자를 기준으로 생각하면 된다. 줄 `linux`에서 커서가 마지막 글자 `x`에 있을 때 `i`를 누르고 ` ubuntu`를 입력하면 `x` 앞에 들어가 `linu ubuntux`가 되고, `a`를 누르고 같은 내용을 입력하면 `x` 뒤에 붙어 `linux ubuntu`가 된다.

## 3. Vi 시작 및 종료

### 3.1 Vi 시작

```bash
vi filename              # 파일 열기 (존재하지 않으면 생성)
vi                       # 빈 버퍼 열기
vi +10 filename          # 파일의 10번째 줄에서 열기
vi +/pattern filename    # 패턴의 첫 번째 위치에서 열기
vi -R filename           # 읽기 전용 모드로 열기
vim filename             # vim 사용 (향상된 vi)
```

`vi filename`에서 지정한 파일이 없으면 빈 파일이 열리고, 처음 저장할 때 그 이름으로 만들어진다. 파일 이름 없이 `vi`만 실행하면 빈 파일이 열리며, 파일 이름은 나중에 `:w 파일명`으로 정할 수 있다.

### 3.2 저장 및 종료

| 모드 | 명령어 | 동작 |
|------|--------|------|
| 마지막 줄 | `:q` | 종료 (변경 사항이 없을 때만) |
| 마지막 줄 | `:q!` | 저장하지 않고 종료 |
| 마지막 줄 | `:w` | 저장 |
| 마지막 줄 | `:w filename` | 다른 파일로 저장 |
| 마지막 줄 | `:wq` | 저장 후 종료 |
| 마지막 줄 | `:wq!` | 강제 저장 후 종료 |
| 명령 | `ZZ` | 저장 후 종료 (Shift+z, Shift+z) |

*표 4. vi의 저장 및 종료 명령*

> **주의:** 저장하지 않은 변경이 있을 때 `:q`를 입력하면 vim은 `E37: No write since last change (add ! to override)` 오류를 출력하고 종료하지 않는다. 변경을 버리려면 `:q!`, 저장하려면 `:wq`를 쓴다.

## 4. 커서 이동

커서 이동 명령은 모두 명령 모드에서 입력한다. 대부분의 명령 앞에 숫자를 붙이면 그 횟수만큼 반복한다(예: `5j`는 아래로 다섯 줄 이동).

### 4.1 기본 이동

| 키 | 동작 |
|----|------|
| `h` | 왼쪽으로 한 문자 이동 |
| `j` | 아래로 한 줄 이동 |
| `k` | 위로 한 줄 이동 |
| `l` | 오른쪽으로 한 문자 이동 |
| 방향키 | h/j/k/l과 동일 |

*표 5. 기본 커서 이동 키*

### 4.2 줄 이동

| 키 | 동작 |
|----|------|
| `0` 또는 `^` | 줄의 시작으로 이동 |
| `$` | 줄의 끝으로 이동 |
| `-` | 이전 줄의 시작으로 이동 |
| `+` 또는 `Enter` | 다음 줄의 시작으로 이동 |

*표 6. 줄 단위 커서 이동 키*

> **참고:** vim에서 `0`은 줄의 첫 번째 열로, `^`는 줄의 공백이 아닌 첫 글자로 이동한다. 들여쓰기가 없는 줄에서는 두 키의 결과가 같다.

### 4.3 단어 이동

| 키 | 동작 |
|----|------|
| `w` | 다음 단어의 시작으로 이동 |
| `W` | 다음 단어로 이동 (공백 구분) |
| `e` | 현재 단어의 끝으로 이동 |
| `E` | 단어의 끝으로 이동 (공백 구분) |
| `b` | 이전 단어의 시작으로 이동 |
| `B` | 이전 단어로 이동 (공백 구분) |

*표 7. 단어 단위 커서 이동 키*

소문자 `w`, `e`, `b`는 영문자, 숫자, 밑줄로 이루어진 연속이나 문장 부호의 연속을 한 단어로 본다. 대문자 `W`, `E`, `B`는 공백으로 구분된 덩어리 전체를 한 단어로 본다. 예를 들어 `user1@myubuntu`에서 `w`는 `@` 앞뒤에서 멈추지만 `W`는 멈추지 않는다.

### 4.4 화면 이동

| 키 | 동작 |
|----|------|
| `Ctrl+f` | 한 페이지 앞으로 (Page Down) |
| `Ctrl+b` | 한 페이지 뒤로 (Page Up) |
| `Ctrl+d` | 반 페이지 앞으로 |
| `Ctrl+u` | 반 페이지 뒤로 |
| `Ctrl+e` | 한 줄 아래로 스크롤 |
| `Ctrl+y` | 한 줄 위로 스크롤 |

*표 8. 화면 단위 이동 키*

### 4.5 특정 위치로 이동

| 키 | 동작 |
|----|------|
| `G` | 파일의 마지막 줄로 이동 |
| `1G` 또는 `gg` | 파일의 첫 번째 줄로 이동 |
| `nG` | n번째 줄로 이동 (예: `20G`) |
| `:n` | n번째 줄로 이동 (마지막 줄 모드) |
| `:0` 또는 `:1` | 첫 번째 줄로 이동 (마지막 줄 모드) |
| `:$` | 마지막 줄로 이동 |
| `H` | 화면 상단으로 이동 |
| `M` | 화면 중간으로 이동 |
| `L` | 화면 하단으로 이동 |

*표 9. 특정 위치로 이동하는 키*

## 5. 편집 명령어

### 5.1 입력 모드 진입

| 키 | 동작 |
|----|------|
| `i` | 커서 앞에 삽입 |
| `I` | 줄의 시작에 삽입 |
| `a` | 커서 뒤에 추가 |
| `A` | 줄의 끝에 추가 |
| `o` | 아래에 새 줄 열기 |
| `O` | 위에 새 줄 열기 |

*표 10. 입력 모드로 전환하는 키*

### 5.2 텍스트 삭제

| 키 | 동작 |
|----|------|
| `x` | 커서 아래 문자 삭제 |
| `nx` | 커서부터 n개 문자 삭제 (예: `3x`) |
| `X` | 커서 앞 문자 삭제 |
| `dw` | 커서에서 단어 끝까지 삭제 |
| `ndw` | 커서부터 n개 단어 삭제 (예: `3dw`) |
| `dd` | 전체 줄 삭제 |
| `d$` 또는 `D` | 커서에서 줄 끝까지 삭제 |
| `d0` | 커서에서 줄 시작까지 삭제 |
| `ndd` | n줄 삭제 (예: `5dd`) |
| `dG` | 현재 줄에서 파일 끝까지 삭제 |
| `d1G` | 현재 줄에서 파일 시작까지 삭제 |

*표 11. 텍스트 삭제 명령*

### 5.3 실행 취소 및 다시 실행

| 키 | 동작 |
|----|------|
| `u` | 마지막 변경 취소 |
| `U` | 현재 줄의 모든 변경 취소 |
| `Ctrl+r` | 다시 실행 (vim에서만) |
| `.` | 마지막 명령 반복 |
| `:e!` | 마지막으로 저장한 내용 이후의 변경을 모두 버리고 파일을 다시 열기 (마지막 줄 모드) |

*표 12. 실행 취소와 반복 명령*

### 5.4 텍스트 대체

| 키 | 동작 |
|----|------|
| `r` | 커서 아래 단일 문자 대체 |
| `R` | 대체 모드 진입 (`Esc`를 누를 때까지 덮어쓰기) |
| `cw` | 단어 변경 (단어 삭제 + 입력 모드 진입) |
| `ncw` | 커서부터 n개 단어 변경 (예: `3cw`) |
| `s` | 커서 아래 문자를 지우고 입력 모드 진입 |
| `ns` | 커서부터 n개 문자를 지우고 입력 모드 진입 (예: `5s`) |
| `cc` 또는 `S` | 전체 줄 변경 |
| `c$` 또는 `C` | 커서에서 줄 끝까지 변경 |
| `~` | 커서 아래 문자의 대소문자 전환 |
| `J` | 현재 줄과 다음 줄 합치기 |

*표 13. 텍스트 대체 명령*

예를 들어 `winux`의 `w`에 커서를 두고 `cw` 또는 `5s`를 입력한 뒤 `editor`를 입력하고 `Esc`를 누르면 `winux`가 `editor`로 바뀐다. `cw`는 단어 끝까지, `5s`는 정확히 다섯 글자를 지운다는 점이 다르다.

## 6. 복사, 잘라내기, 붙여넣기

### 6.1 Yank(복사)와 Put(붙여넣기)

| 키 | 동작 |
|----|------|
| `yy` 또는 `Y` | 현재 줄 복사 (yank) |
| `nyy` | n줄 복사 (예: `5yy`) |
| `yw` | 단어 복사 |
| `y$` | 커서에서 줄 끝까지 복사 |
| `dd`, `ndd` | 현재 줄부터 한 줄 또는 n줄 잘라내기 (삭제와 같은 명령) |
| `p` | 커서 뒤/현재 줄 아래에 붙여넣기 (put) |
| `P` | 커서 앞/현재 줄 위에 붙여넣기 (put) |

*표 14. 복사, 잘라내기, 붙여넣기 명령*

vi에서 잘라내기는 별도의 명령이 아니라 삭제이다. `dd`나 `x`로 지운 내용은 버퍼에 저장되므로 `p`나 `P`로 다시 붙일 수 있다. 줄 단위로 복사하거나 지운 내용은 현재 줄의 아래(`p`)나 위(`P`)에 붙고, 글자나 단어 단위의 내용은 커서의 뒤(`p`)나 앞(`P`)에 붙는다.

### 6.2 이름 있는 버퍼 (레지스터)

```text
"ayy        # 현재 줄을 레지스터 'a'에 복사
"ap         # 레지스터 'a'에서 붙여넣기
"bdd        # 현재 줄을 레지스터 'b'에 삭제(잘라내기)
```

이름을 붙이지 않고 쓰는 기본 버퍼를 **언네임드 버퍼(unnamed buffer)** 라고 한다. 명령 앞에 `"`와 이름을 붙여 쓰는 버퍼는 **네임드 버퍼(named buffer)** 라고 하며, `"a`부터 `"z`까지 영문자 26개를 쓸 수 있다. 숫자 버퍼 `"1`부터 `"9`까지에는 최근에 삭제한 줄이 차례로 저장된다. 네임드 버퍼를 쓰면 여러 내용을 따로 보관했다가 원하는 곳에 붙일 수 있다. 예를 들어 `"bP`는 `"b` 버퍼의 내용을 현재 줄 위에 붙인다.

### 6.3 마지막 줄 모드에서 복사, 잘라내기, 붙여넣기

`:`를 입력하여 마지막 줄 모드로 전환하면 줄 번호나 범위를 지정하여 복사, 잘라내기, 붙이기를 할 수 있다. 범위는 다음 기호로 지정한다.

| 범위 | 의미 |
|------|------|
| `1,$` 또는 `%` | 1번째 줄부터 마지막 줄까지 |
| `1,.` | 1번째 줄부터 커서가 있는 줄까지 |
| `.,$` | 커서가 있는 줄부터 마지막 줄까지 |
| `.-3,.` | 커서가 있는 줄과 그 앞의 세 줄 (총 네 줄) |
| `10,20` | 10번째 줄부터 20번째 줄까지 |

*표 15. 마지막 줄 모드의 범위 지정*

`.`은 커서가 있는 줄, `$`는 마지막 줄을 뜻한다. 범위는 보통 `10,20`처럼 쉼표 앞뒤에 공백 없이 쓴다.

| 명령 | 기능 |
|------|------|
| `:#y` | # 번째 줄을 복사한다 (예: `:3y`는 세 번째 줄을 복사). |
| `:범위y` | 범위의 줄을 복사한다 (예: `:2,4y`는 2~4번째 줄을 복사). |
| `:#d` | # 번째 줄을 잘라낸다 (예: `:3d`는 세 번째 줄을 삭제). |
| `:범위d` | 범위의 줄을 잘라낸다 (예: `:1,4d`는 1~4번째 줄을 삭제). |
| `:pu` | 현재 줄 다음에 버퍼의 내용을 붙인다. |
| `:#pu` | # 번째 줄 다음에 버퍼의 내용을 붙인다 (예: `:4pu`). |

*표 16. 마지막 줄 모드의 복사, 잘라내기, 붙여넣기 명령*

예를 들어 `:2,3d`는 2번째와 3번째 줄을 잘라내고, `:1,2y`는 1번째와 2번째 줄을 복사한다. 이어서 `:2pu`를 입력하면 버퍼의 내용이 2번째 줄 다음에, `:4pu`를 입력하면 4번째 줄 다음에 붙는다.

## 7. 검색 및 바꾸기

### 7.1 검색

| 명령어 | 동작 |
|--------|------|
| `/pattern` | 앞으로 패턴 검색 |
| `?pattern` | 뒤로 패턴 검색 |
| `n` | 같은 방향으로 검색 반복 |
| `N` | 반대 방향으로 검색 반복 |
| `*` | 커서 아래 단어를 앞으로 검색 |
| `#` | 커서 아래 단어를 뒤로 검색 |

*표 17. 검색 명령*

`/`를 누르면 커서가 마지막 줄로 이동하고, 검색할 문자열을 입력한 뒤 `Enter`를 누르면 커서가 일치하는 다음 위치로 간다. 파일 끝에 닿으면 vim은 `search hit BOTTOM, continuing at TOP` 메시지를 출력하고 파일 처음부터 검색을 계속한다. `?`로 위쪽을 검색하다가 파일 처음에 닿으면 반대로 파일 끝에서 계속한다.

### 7.2 검색 및 바꾸기 (치환)

```vim
:s/old/new/              # 현재 줄에서 첫 번째 항목 바꾸기
:s/old/new/g             # 현재 줄의 모든 항목 바꾸기
:n,ms/old/new/g          # n줄부터 m줄까지 모든 항목 바꾸기
:%s/old/new/g            # 전체 파일의 모든 항목 바꾸기
:%s/old/new/gc           # 확인을 요청하며 모든 항목 바꾸기
:1,$s/old/new/g          # :%s/old/new/g와 동일
```

바꾸기 명령의 일반 형식은 `:범위s/문자열1/문자열2/플래그`이다. 범위를 생략하면 현재 줄만 대상이 되고, `g` 플래그가 없으면 각 줄에서 처음 나오는 문자열1만 바뀐다. `c` 플래그를 붙이면 바꿀 때마다 수정할지 묻는다. 예를 들어 `:3,4s/editor/ubuntu/`는 3번째와 4번째 줄에서 각각 처음 나오는 `editor`만 `ubuntu`로 바꾸고, `:%s/like/LIKE/g`는 파일의 모든 `like`를 `LIKE`로 바꾼다.

## 8. 파일 다루기와 셸 명령

### 8.1 파일 읽어 오기와 여러 파일 편집

| 명령 | 기능 |
|------|------|
| `:r 파일` | 지정한 파일을 읽어 들여 현재 커서 위치(현재 줄 다음)에 삽입한다. |
| `:e 파일` | 지정한 파일로 전환한다. 현재 파일을 `:w`로 저장한 뒤에 실행해야 한다. |
| `:e! 파일` | 현재 파일의 저장하지 않은 변경을 버리고 지정한 파일로 전환한다. |
| `:n` | vi를 시작할 때 여러 파일을 지정했으면 다음 파일로 이동한다. |

*표 18. 파일 관련 명령*

`vi a.txt b.txt`처럼 파일을 여러 개 지정하여 시작하면 첫 파일부터 편집하고, `:n`으로 다음 파일로 넘어간다. 현재 파일을 저장하지 않은 채 `:e`나 `:n`으로 다른 파일로 가려고 하면 오류가 발생하므로, 먼저 `:w`로 저장하거나 `!`를 붙여 변경을 버린다.

### 8.2 vi에서 셸 명령 실행

| 명령 | 기능 |
|------|------|
| `:!셸 명령` | vi 작업을 잠시 중단하고 셸 명령을 실행한다. vi로 돌아오려면 `Enter`를 누른다. |
| `:sh` | vi를 잠시 빠져나가 셸을 실행한다. vi로 돌아오려면 `exit`를 입력한다. |

*표 19. vi에서 셸 명령을 실행하는 명령*

`:!`는 명령 하나를 실행하고 바로 돌아올 때, `:sh`는 셸에서 여러 명령을 실행해야 할 때 쓴다. 예를 들어 파일을 저장한 뒤 `:!pwd`를 입력하면 vi를 끝내지 않고 현재 디렉터리의 경로를 확인할 수 있다.

### 8.3 기타 명령키

| 명령키 | 기능 |
|--------|------|
| `Ctrl+l` (소문자 L) | 현재 화면을 다시 출력한다. |
| `Ctrl+g` | 현재 커서 위치의 줄 번호를 마지막 줄에 출력한다. |
| `J` (Shift+j) | 현재 줄과 아래 줄을 연결하여 한 줄로 만든다. |
| `.` (마침표) | 바로 직전에 했던 명령을 반복한다. |
| `~` (틸드) | 커서 위치의 글자를 대문자나 소문자로 바꾼다. |

*표 20. 기타 명령키*

예를 들어 1번째 줄에서 `J`를 누르면 1번째와 2번째 줄이 한 줄이 되고, 이어서 `.`을 누르면 같은 연결이 한 번 더 일어난다. 커서를 `u`에 두고 `~`를 누르면 `U`로 바뀐다.

### 8.4 기타 유용한 명령어

```vim
:!command                # vi를 종료하지 않고 셸 명령어 실행
:r filename              # 파일 내용을 읽어서 삽입
:r !command              # 명령어 출력 삽입
:n                       # 다음 파일로 이동 (여러 파일 편집 시)
:prev                    # 이전 파일로 이동
:split filename          # 가로로 창 분할
:vsplit filename         # 세로로 창 분할
Ctrl+w w                 # 분할된 창 간 전환
```

## 9. Vi 환경 설정

### 9.1 Set 명령어

| 명령어 | 동작 |
|--------|------|
| `:set nu` 또는 `:set number` | 줄 번호 표시 (화면에 보이기만 할 뿐 파일에 저장되지 않음) |
| `:set nonu` | 줄 번호 숨기기 |
| `:set list` | 눈에 보이지 않는 특수 문자 표시 (탭은 `^I`, 줄 끝은 `$`) |
| `:set nolist` | 특수 문자 숨기기 |
| `:set ai` | 자동 들여쓰기 |
| `:set noai` | 자동 들여쓰기 비활성화 |
| `:set ic` | 검색 시 대소문자 무시 |
| `:set noic` | 검색 시 대소문자 구분 |
| `:set ts=4` | 탭 간격을 4칸으로 설정 |
| `:set showmode` | 현재 모드 표시 |
| `:set noshowmode` | 현재 모드 숨기기 |
| `:set` | set으로 설정한 모든 vi 환경 설정 값 표시 |
| `:set all` | 모든 설정 표시 |
| `:set syntax=on` | 구문 강조 활성화 |

*표 21. vi 환경 설정 명령*

### 9.2 영구 설정 (~/.vimrc)

```vim
" ~/.vimrc - Vim 설정 파일
set number              " 줄 번호 표시
set autoindent          " 새 줄 자동 들여쓰기
set tabstop=4           " 탭 너비 = 4칸
set shiftwidth=4        " 들여쓰기 너비 = 4칸
set expandtab           " 탭을 공백으로 변환
set hlsearch            " 검색 결과 강조
set ignorecase          " 대소문자 무시 검색
set smartcase           " 대문자 사용 시 대소문자 구분
set showmatch           " 대응하는 괄호 강조
syntax on               " 구문 강조 활성화
set encoding=utf-8      " UTF-8 인코딩
```

`:set`으로 바꾼 설정은 vi를 종료하면 사라진다. 설정 파일에 적어 두면 vi를 시작할 때마다 자동으로 적용되며, 파일 안에서는 앞의 콜론 없이 `set number`처럼 쓴다.

### 9.3 .exrc 파일과 EXINIT 환경 변수

사용자 홈 디렉터리의 `.exrc` 파일에 vi 환경 설정을 저장하면 그 사용자가 여는 모든 파일에 같은 설정이 적용된다. 셸의 환경 변수 `EXINIT`에 설정을 넣어도 된다.

```text
set nu
set list
set showmode
```

```bash
EXINIT='set nu list'
export EXINIT
```

> **참고:** vim은 시작할 때 `VIMINIT` 환경 변수, `~/.vimrc`, `EXINIT` 환경 변수, `~/.exrc`를 차례로 찾아 처음 발견한 하나만 사용한다. 따라서 `~/.vimrc`가 있으면 `EXINIT`과 `~/.exrc`의 설정은 읽히지 않는다.

## 10. 모범 사례

### 10.1 생산성 팁

- vim에서는 `gg=G`로 전체 파일을 자동 들여쓰기할 수 있다.
- `.`으로 마지막 명령을 반복하면 같은 편집을 여러 곳에 빠르게 적용할 수 있다.
- `ciw`를 쓰면 커서가 단어 중간에 있어도 단어 전체(inner word)를 한 번에 바꿀 수 있다.
- vim에서는 `v`, `V`, `Ctrl+v`의 비주얼 모드로 글자, 줄, 사각형 블록을 선택할 수 있다.
- 방향키 대신 `hjkl` 탐색을 익히면 손을 기본 위치에서 떼지 않고 커서를 옮길 수 있다.

### 10.2 Vi vs. Nano vs. Emacs

| 기능 | Vi/Vim | Nano | Emacs |
|------|--------|------|-------|
| 학습 곡선 | 가파름 | 쉬움 | 가파름 |
| 어디서나 사용 가능 | 예 | 대체로 | 대체로 |
| 확장성 | 높음 (Vim) | 낮음 | 매우 높음 |
| 모달 편집 | 예 | 아니오 | 아니오 |
| 속도 (숙련 사용자) | 매우 빠름 | 보통 | 빠름 |

### 10.3 Vim 실습: 프로그램 작성과 실행

vi는 프로그램 소스 코드를 작성하는 데에도 쓰인다. 예를 들어 **C 프로그램** 또는 **Python 프로그램**을 작성하고 실행하여 구구단(1~9단)을 출력할 수 있다. C 코드는 `gcc`로 컴파일하고, Python 코드는 `python3`으로 실행한다. 컴파일러나 인터프리터가 없으면 root 권한으로 먼저 설치한다.

```bash
# apt install gcc          # C 컴파일러 설치 (root)
$ vim a.c                  # 소스 코드 작성 후 :wq
$ gcc -o a a.c             # a.c를 컴파일하여 실행 파일 a 생성
$ ./a                      # 실행

# apt install python3      # Python 설치 (root)
$ vim a.py
$ python3 a.py
```

```c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= 9; j++)
            printf("%d x %d = %2d\n", i, j, i * j);
        printf("\n");
    }
    return 0;
}
```

```python
for i in range(1, 10):
    for j in range(1, 10):
        print(f"{i} x {j} = {i * j:2d}")
    print()
```

두 프로그램은 같은 내용을 출력한다. 바깥 반복문이 단(`i`)을, 안쪽 반복문이 곱하는 수(`j`)를 1부터 9까지 바꾸며, 한 단이 끝날 때마다 빈 줄을 하나 출력한다. 출력은 `1 x 1 =  1`로 시작하여 `9 x 9 = 81`로 끝난다.

## 요약

| 개념 | 핵심 요약 |
|------|-----------|
| Vi 모드 | 명령 모드(기본), 입력 모드(`i/a/o`), 마지막 줄 모드(`:`)가 있으며 `Esc`로 명령 모드에 돌아온다. |
| 종료 | `:q`(종료), `:wq`(저장 후 종료), `:q!`(저장하지 않고 종료), `ZZ`(저장 후 종료)로 vi를 끝낸다. |
| 이동 | `hjkl`(기본), `w/b/e`(단어), `0/$`(줄), `G/gg`(파일)로 커서를 옮긴다. |
| 삽입 | `i`(앞), `a`(뒤), `o`(아래 새 줄)와 그 변형 `I/A/O`로 입력 모드에 들어간다. |
| 삭제 | `x`(문자), `dw`(단어), `dd`(줄), `D`(줄 끝까지)로 지우며, 지운 내용은 버퍼에 남는다. |
| 복사/붙여넣기 | `yy`(줄 복사), `p`(뒤에 붙여넣기), `P`(앞에 붙여넣기)를 쓰고, `"a`처럼 네임드 버퍼를 지정할 수 있다. |
| 마지막 줄 모드 편집 | `:2,4y`, `:3d`, `:4pu`처럼 줄 번호와 범위(`.`, `$`, `%`)로 복사, 잘라내기, 붙이기를 한다. |
| 검색 | `/pattern`(앞으로), `?pattern`(뒤로), `n/N`(다음/이전)으로 문자열을 찾는다. |
| 바꾸기 | `:%s/old/new/g`는 파일 전체를, `:%s/old/new/gc`는 확인을 받으며 바꾼다. |
| 파일과 셸 | `:r`, `:e`, `:n`으로 다른 파일을 다루고, `:!`와 `:sh`로 셸 명령을 실행한다. |
| 설정 | `:set nu`는 현재 세션에만, `~/.vimrc`나 `~/.exrc`는 영구적으로 적용된다. |

## 점검 문제

1. **마지막 줄 모드 편집:** `one`, `two`, `three`, `four`, `five`의 다섯 줄로 된 파일에서 `:2,3d`, `:1y`, `:$pu`를 차례로 입력했다. 파일의 최종 내용을 쓰라.

   <details>
   <summary>정답</summary>

   `:2,3d`는 2번째 줄 `two`와 3번째 줄 `three`를 잘라내어 `one`, `four`, `five`가 남는다. `:1y`는 1번째 줄 `one`을 버퍼에 복사하고, `:$pu`는 마지막 줄 `five` 다음에 버퍼의 내용을 붙인다. 따라서 최종 내용은 `one`, `four`, `five`, `one`의 네 줄이다.

   </details>

2. **네임드 버퍼:** `A`, `B`, `C`, `D`의 네 줄로 된 파일에서 커서를 2번째 줄에 두고 `"add`, `"bdd`를 입력한 뒤, `gg`로 1번째 줄에 가서 `"bP`, `"ap`를 입력했다. 파일의 최종 내용을 쓰라.

   <details>
   <summary>정답</summary>

   `"add`는 2번째 줄 `B`를 `"a` 버퍼로 잘라내고, 커서는 새 2번째 줄 `C`에 놓인다. `"bdd`는 `C`를 `"b` 버퍼로 잘라내어 `A`, `D`가 남는다. 1번째 줄에서 `"bP`는 `C`를 현재 줄 위에 붙여 `C`, `A`, `D`가 되고 커서는 `C`에 놓인다. `"ap`는 `B`를 현재 줄 아래에 붙인다. 따라서 최종 내용은 `C`, `B`, `A`, `D`이다.

   </details>

3. **수정 명령 비교:** `abc winux def`에서 커서가 `winux`의 `w`에 있을 때 `cw`, `5s`, `R` 중 하나를 누르고 `editor`를 입력한 뒤 `Esc`를 누른다. 각 경우의 결과와 차이를 설명하라.

   <details>
   <summary>정답</summary>

   `cw`는 커서부터 단어 끝까지(`winux`)를 지우고 입력 모드에 들어가므로 결과는 `abc editor def`이다. `5s`는 커서부터 정확히 다섯 글자(`winux`)를 지우고 입력 모드에 들어가므로 결과가 같다. `R`은 지우지 않고 입력한 글자 수만큼 기존 글자를 덮어쓰므로, 여섯 글자 `editor`가 `winux`와 뒤의 공백까지 덮어써 `abc editordef`가 된다.

   </details>

4. **파일 전환:** `test.txt`를 수정한 뒤 저장하지 않고 `:e exec.txt`를 입력했다. 어떤 일이 일어나며, `exec.txt`로 넘어가는 방법 두 가지는 무엇인가?

   <details>
   <summary>정답</summary>

   저장하지 않은 변경이 있으므로 vim은 `E37: No write since last change (add ! to override)` 오류를 출력하고 파일을 전환하지 않는다. 변경을 보존하려면 `:w`로 저장한 뒤 `:e exec.txt`를 입력하고, 변경을 버려도 되면 `:e! exec.txt`를 입력한다.

   </details>
