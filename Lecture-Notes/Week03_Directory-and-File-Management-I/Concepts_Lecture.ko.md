## 1. Linux 파일과 디렉터리

### 1.1 모든 것은 파일이다

**파일(file)** 은 관련 있는 정보의 집합이다. Linux에서는 장치와 디렉터리를 포함하여 거의 모든 것이 파일로 취급된다. 디렉터리도 파일의 한 종류로서 그 안에 저장된 파일과 하위 디렉터리에 대한 정보를 담고, 하드디스크나 키보드 같은 장치도 장치 파일로 다룬다. 또 Linux에서 확장자는 관례일 뿐 파일의 종류를 정하지 않으므로, 확장자가 없는 파일도 많다.

### 1.2 파일 유형

| 유형 | `ls -l`에서의 기호 | 설명 |
|------|-------------------|------|
| 일반 파일 | `-` | 텍스트 파일, 실행 파일, 이미지, 데이터 파일 |
| 디렉터리 | `d` | 다른 파일 및 디렉터리에 대한 참조를 포함 |
| 심볼릭 링크 | `l` | 원본 파일을 다른 이름으로 가리키는 파일 (Windows 바로가기와 유사) |
| 블록 장치 | `b` | 블록 단위로 읽고 쓰는 장치 (예: 하드 디스크 `/dev/sda`) |
| 문자 장치 | `c` | 문자 단위로 읽고 쓰는 장치 (예: 키보드, 터미널) |
| 파이프 | `p` | 프로세스 간 통신을 위한 이름 있는 파이프 |
| 소켓 | `s` | 프로세스 간 통신에 쓰는 소켓 파일 (Unix 도메인 소켓) |

*표 1. Linux의 파일 유형과 ls -l의 표시 기호*

### 1.3 파일 유형 식별

`file` 명령은 파일의 내용을 검사하여 그 종류를 알려 준다.

```bash
# 'file' 명령어를 사용하여 파일 유형 확인
$ file .profile
.profile: ASCII text

$ file /bin/bash
/bin/bash: ELF 64-bit LSB pie executable, x86-64

$ file /home
/home: directory
```

## 2. 디렉터리 계층 구조

### 2.1 디렉터리 트리

Linux의 디렉터리는 루트 디렉터리를 꼭대기로 하는 트리 형태의 계층 구조를 이룬다.

- **루트 디렉터리(root directory):** 계층 구조의 최상위 디렉터리이며 `/`로 표시한다.
- **서브디렉터리(subdirectory):** 특정 디렉터리의 아래에 있는 디렉터리이다.
- **부모 디렉터리와 자식 디렉터리:** 어떤 디렉터리의 바로 위 디렉터리를 부모 디렉터리(상위 디렉터리), 바로 아래 디렉터리를 자식 디렉터리(하위 디렉터리)라 한다.
- **작업 디렉터리(working directory):** 현재 작업 중인 디렉터리이며 `pwd` 명령으로 확인한다.
- **홈 디렉터리(home directory):** 사용자 계정에 할당된 기본 디렉터리로, 로그인하면 처음 작업 디렉터리가 된다.

```text
/                          # 루트 디렉터리 (계층 구조의 최상위)
├── bin/                   # 필수 사용자 명령어 바이너리 (-> /usr/bin)
├── boot/                  # 부트 로더 파일 (커널, initramfs)
├── dev/                   # 장치 파일
├── etc/                   # 시스템 설정 파일
├── home/                  # 사용자 홈 디렉터리
│   ├── user1/
│   └── user2/
├── lib/                   # 필수 공유 라이브러리
├── media/                 # 이동식 미디어 마운트 지점
├── mnt/                   # 임시 마운트 지점
├── opt/                   # 선택적/추가 패키지
├── proc/                  # 프로세스/커널 정보용 가상 파일시스템
├── root/                  # Root 사용자의 홈 디렉터리
├── run/                   # 실행 중인 서비스의 런타임 데이터
├── srv/                   # 서비스 데이터 (FTP, 웹)
├── sys/                   # 커널 및 장치 정보
├── tmp/                   # 임시 파일 (재부팅 시 삭제됨)
├── usr/                   # Unix 시스템 자원
│   ├── bin/               # 사용자 명령어
│   ├── lib/               # 라이브러리
│   └── local/             # 로컬 설치 소프트웨어
└── var/                   # 가변 데이터 (로그, 스풀, 캐시)
    └── log/               # 시스템 로그 파일
```

*그림 1. Linux의 디렉터리 트리*

Ubuntu는 `/bin`, `/sbin`, `/lib`를 각각 `/usr/bin`, `/usr/sbin`, `/usr/lib`를 가리키는 심볼릭 링크로 둔다. 그림 1의 `-> /usr/bin`이 이 관계를 나타내며, `ls -F /`로 보면 `bin@`처럼 이름 뒤에 `@`가 붙는다.

### 2.2 주요 디렉터리

| 디렉터리 | 용도 | 비고 |
|----------|------|------|
| `/` | 파일 시스템의 루트 | 모든 것이 여기서 시작됨 |
| `/home` | 사용자 홈 디렉터리 | 각 사용자는 `/home/username`을 가짐 |
| `/etc` | 설정 파일 | 시스템 전체 설정 |
| `/var` | 가변 데이터 | 로그, 메일, 데이터베이스 |
| `/tmp` | 임시 파일 | 재부팅 시 삭제됨 |
| `/proc` | 프로세스 정보 | 가상 파일 시스템 (메모리에만 존재) |
| `/usr` | Unix 시스템 자원 | 기본 실행 파일, 라이브러리, 헤더 파일, 문서 |
| `/root` | Root 사용자 홈 | `/`(루트 디렉터리)와 다름 |
| `/lost+found` | 복구된 파일 | 파일 시스템에 문제가 생겨 복구할 때 문제가 된 파일이 저장되며, 보통 비어 있음 |

*표 2. 주요 디렉터리의 용도*

> **참고:** usr를 Unix System Resources의 약자로 풀이하기도 하지만, 원래는 초기 Unix에서 사용자(user)의 홈 디렉터리를 두던 곳이라 붙은 이름이다.

> **핵심:** `/proc`는 하드 디스크에 저장되지 않고 커널이 메모리 상에서 만들어 보여 주는 가상 파일 시스템이다. 실시간 커널 및 프로세스 정보를 제공한다.

## 3. 절대 경로와 상대 경로

### 3.1 절대 경로

- **항상 `/`로 시작한다.** `/`는 루트 디렉터리이다.
- 루트 디렉터리부터 대상 파일이나 디렉터리까지 거치는 중간 디렉터리의 이름을 모두 적는다.
- 현재 디렉터리와 관계없이 항상 같은 위치를 가리킨다.

```text
/home/user1/Documents/report.txt
/etc/hostname
/usr/bin/ls
```

### 3.2 상대 경로

- **`/`로 시작하지 않는다.**
- 현재 작업 디렉터리를 기준으로 한다. 하위 디렉터리로 내려갈 때는 그 디렉터리 이름으로 바로 시작하고, 상위 디렉터리로 올라갈 때는 `..`으로 시작한다.
- `.`(현재 디렉터리)과 `..`(상위 디렉터리)를 사용하며, 같은 대상이라도 현재 디렉터리에 따라 상대 경로가 달라진다.

```text
# 현재 디렉터리가 /home/user1인 경우
Documents/report.txt        # /home/user1/Documents/report.txt와 동일
../user2/file.txt           # /home/user2/file.txt와 동일
./script.sh                 # /home/user1/script.sh와 동일
```

예를 들어 현재 디렉터리가 `/usr/lib`이면 `/usr/bin/ls`는 상대 경로 `../bin/ls`로 가리킬 수 있다.

### 3.3 특수 디렉터리 기호

| 기호 | 의미 | 예시 |
|------|------|------|
| `.` | 현재 디렉터리 | `./script.sh` |
| `..` | 상위 디렉터리 | `cd ..` |
| `~` | 홈 디렉터리 | `cd ~` 또는 `cd` |
| `~user` | 다른 사용자의 홈 | `cd ~user2` |
| `-` | 이전 디렉터리 | `cd -` |

*표 3. 특수 디렉터리 기호*

## 4. 파일 및 디렉터리 이름 규칙

### 4.1 규칙

- 이름에 `/`를 사용할 수 없다. `/`는 경로의 구분자이기 때문이다.
- 문자, 숫자, 하이픈(`-`), 밑줄(`_`), 마침표(`.`)를 사용할 수 있다.
- `/`를 제외한 특수 문자도 쓸 수 있지만, `>`, `|`, `:`, `&`, 공백 문자는 피하는 것이 좋다.
- **대소문자 구분:** `File.txt`와 `file.txt`는 서로 다른 파일이다.
- `.`으로 시작하는 이름은 숨김 파일로 간주된다.
- 널 문자(`\0`)는 사용할 수 없다.
- 파일 이름의 최대 길이는 일반적으로 255바이트이다(ext4 기준). UTF-8에서 한글은 한 글자가 3바이트이므로 한글 이름은 더 짧아진다.

### 4.2 예시

| 좋은 이름 | 나쁜 이름 | 잘못된 이름 |
|-----------|-----------|-------------|
| `game.txt` | `&game` | `myhome/` |
| `hello.c` | `*dir` | `/test` |
| `test` | `my home` | `bad/name` |
| `sample11` | `game\` | |

*표 4. 좋은 이름, 나쁜 이름, 사용할 수 없는 이름의 예*

## 5. 디렉터리 명령어

### 5.1 pwd: 현재 작업 디렉터리 출력

`pwd`(print working directory)는 현재 디렉터리의 절대 경로를 출력한다.

```bash
$ pwd
/home/user1
```

### 5.2 cd: 디렉터리 변경

```bash
cd /tmp                 # 절대 경로
cd ../usr/lib           # 상대 경로
cd ~                    # 홈 디렉터리
cd                      # 홈 디렉터리 (단축키)
cd -                    # 이전 디렉터리
cd ..                   # 상위 디렉터리
```

위의 `cd ../usr/lib`는 현재 디렉터리가 `/tmp`일 때 상위 디렉터리인 `/`를 거쳐 `/usr/lib`로 이동한다.

### 5.3 ls: 디렉터리 내용 목록

```bash
ls                      # 현재 디렉터리 목록
ls -a                   # 숨김 파일 표시 (.으로 시작하는 파일)
ls -l                   # 상세 형식 (자세한 정보)
ls -la                  # 상세 형식 + 숨김 파일
ls -lh                  # 사람이 읽기 쉬운 파일 크기
ls -R                   # 재귀적 목록
ls -F                   # 유형 표시자 추가 (*=실행 파일, /=디렉터리, @=링크)
ls -i                   # inode 번호 표시
ls -d                   # 내용이 아닌 디렉터리 자체 표시
ls -t                   # 수정 시간순 정렬
ls -S                   # 파일 크기순 정렬
```

이 밖에 `-A`는 `.`과 `..`을 제외한 모든 파일을, `-L`은 심볼릭 링크의 경우 원본 파일의 정보를 출력한다. `ls /tmp`처럼 디렉터리 이름을 인자로 주면 그 디렉터리의 내용을 출력하고, `ls .bashrc`처럼 파일 이름을 주면 파일이 있는지 확인할 수 있다(없으면 `ls: cannot access 'game': No such file or directory` 같은 오류가 출력된다). `ls -ld /`처럼 여러 옵션을 한꺼번에 쓸 수도 있다.

**`ls -l` 출력 이해:**

```text
drwxr-xr-x  2  user1  user1  4096  Mar 21 12:05  Documents
│└─┬──┘└┬─┘ │   │       │      │       │            │
│  │    │   │   │       │      │       │            └── 파일 이름
│  │    │   │   │       │      │       └── 최종 수정일
│  │    │   │   │       │      └── 크기 (바이트)
│  │    │   │   │       └── 그룹 소유자
│  │    │   │   └── 파일 소유자
│  │    │   └── 하드 링크 수
│  │    └── 기타 사용자 권한 (r-x)
│  └── 그룹 권한 (r-x)
│       소유자 권한 (rwx)
└── 파일 유형 (d=디렉터리, -=파일, l=링크)
```

*그림 2. ls -l 출력의 필드 구성*

### 5.4 mkdir: 디렉터리 생성

```bash
mkdir mydir                     # 단일 디렉터리 생성
mkdir -p parent/child/grandchild  # 중첩 디렉터리 생성
mkdir dir1 dir2 dir3            # 여러 디렉터리 생성
```

`-p` 없이 `mkdir temp/mid/han`처럼 중간 디렉터리가 없는 경로를 주면 `No such file or directory` 오류가 난다. `-p`를 쓰면 없는 중간 디렉터리를 자동으로 만든 뒤 지정한 디렉터리를 만든다.

### 5.5 rmdir: 빈 디렉터리 제거

```bash
rmdir mydir                     # 빈 디렉터리만 제거
rmdir -p parent/child/grandchild  # 중첩된 빈 디렉터리 제거
```

`rmdir -p`는 지정한 디렉터리를 지운 뒤, 그 부모 디렉터리가 빈 디렉터리가 되면 부모 디렉터리도 차례로 지운다. 비어 있지 않은 디렉터리는 `rmdir`로 지울 수 없으며(`rmdir: failed to remove 'temp': Directory not empty`), 이때는 4주차에서 다루는 `rm -r`을 쓴다.

### 5.6 유사 명령어: dir, vdir

```bash
dir                 # ls와 유사 (기본 색상 없음)
vdir                # ls -l과 유사
```

## 6. 파일 내용 명령어

### 6.1 cat: 연결 및 표시

```bash
cat file.txt                    # 전체 파일 표시
cat -n file.txt                 # 줄 번호 표시
cat file1.txt file2.txt         # 여러 파일 연결
cat > newfile.txt               # stdin에서 파일 생성 (Ctrl+D로 종료)
cat >> existingfile.txt         # stdin에서 파일에 추가
```

### 6.2 more와 less: 파일 페이지 넘기기

```bash
more file.txt                   # 주로 앞으로 페이지 넘기기
less file.txt                   # 앞뒤로 페이지 넘기기 (권장)
```

`more`는 내용을 화면 단위로 출력하며, `Space`를 누르면 다음 화면을, `Enter`를 누르면 한 줄씩 스크롤하고, `more +20 file.txt`처럼 출력을 시작할 줄 번호를 지정할 수도 있다. 파일을 볼 때는 `b`로 한 화면 뒤로 갈 수 있지만, 파이프로 받은 입력은 뒤로 넘길 수 없다. `less` 안에서는 다음 키로 이동하고 검색한다.

| 키 | 동작 |
|----|------|
| `Space` / `f` / `Ctrl + F` | 다음 페이지 |
| `b` / `Ctrl + B` | 이전 페이지 |
| `j` / `↓` | 한 줄 아래로 스크롤 |
| `k` / `↑` | 한 줄 위로 스크롤 |
| `g` | 처음으로 이동 |
| `G` | 끝으로 이동 |
| `/pattern` | 앞으로 검색 |
| `?pattern` | 뒤로 검색 |
| `n` | 다음 검색 결과 |
| `q` | 종료 |

*표 5. less의 탐색 키*

### 6.3 head와 tail: 파일 부분 보기

```bash
head file.txt                   # 처음 10줄 (기본값)
head -n 20 file.txt             # 처음 20줄
head -n -5 file.txt             # 마지막 5줄을 제외한 모든 줄

tail file.txt                   # 마지막 10줄 (기본값)
tail -n 20 file.txt             # 마지막 20줄
tail -f /var/log/syslog         # 실시간으로 로그 추적
```

`head`와 `tail`은 `-n 20` 대신 `-20`처럼 숫자만 옵션으로 줄 수도 있다. `tail -n +20 file.txt`처럼 줄 수 앞에 `+`를 붙이면 20번째 줄부터 끝까지 출력한다. `tail -f`는 출력을 끝내지 않고 파일에 새로 추가되는 내용을 계속 출력하며, `Ctrl + C`로 멈춘다.

> **핵심:** `tail -f`는 로그 파일에 어떤 내용이 실시간으로 추가되는지 모니터링할 때 유용하다.

## 7. 모범 사례

### 7.1 탐색 팁

- `Tab` 자동 완성을 사용하여 경로의 오타를 방지한다.
- `cd -`를 사용하여 두 디렉터리 사이를 오간다.
- `pushd`와 `popd`로 디렉터리 스택을 관리하며 이동할 수 있다.
- 스크립트에서는 현재 디렉터리에 영향을 받지 않도록 절대 경로를 쓰는 것이 안전하다.

### 7.2 흔한 실수

| 실수 | 올바른 방법 |
|------|------------|
| 파일 이름에 공백 사용 | 밑줄이나 하이픈 사용 |
| 대소문자 구분 잊기 | Linux는 대소문자를 구분함 |
| `/root`와 `/` 혼동 | `/root`는 root의 홈이고, `/`는 파일 시스템의 루트 |
| `rm -rf /` 사용 | 절대 실행하지 않음. 시스템 전체가 삭제될 수 있으며, GNU `rm`은 기본적으로 `/` 자체의 재귀 삭제를 거부하지만(`--preserve-root`) `rm -rf /*`는 막지 못함 |

## 점검 문제

1. **상대 경로 작성:** 현재 디렉터리가 `/usr/lib`일 때 `/usr/bin/ls`와 `/etc/hostname`을 각각 상대 경로로 쓰라.

   <details>
   <summary>정답</summary>

   `/usr/bin/ls`는 `..`으로 `/usr`에 올라간 뒤 `bin/ls`로 내려가므로 `../bin/ls`이다. `/etc/hostname`은 `..`을 두 번 써서 `/`까지 올라간 뒤 `etc/hostname`으로 내려가므로 `../../etc/hostname`이다.

   </details>

2. **유형 표시자:** Ubuntu에서 `ls -F /`의 출력에 `bin@`, `boot/`가 나타났다. `@`와 `/`는 각각 무엇을 뜻하며, 실행 파일에는 어떤 표시가 붙는가?

   <details>
   <summary>정답</summary>

   `@`는 심볼릭 링크라는 뜻으로, `/bin`이 `/usr/bin`을 가리키는 심볼릭 링크임을 보여 준다. `/`는 디렉터리라는 뜻이다. 실행 파일에는 이름 뒤에 `*`가 붙는다.

   </details>

3. **rmdir의 동작:** 빈 디렉터리 `a/b/c`가 있고 `a`와 `b`에는 다른 내용이 없다. `rmdir -p a/b/c`를 실행하면 어떻게 되는가? 또 `c` 안에 파일이 하나 있으면 어떻게 되는가?

   <details>
   <summary>정답</summary>

   먼저 `a/b/c`가 지워지고, 그러면 `b`가 빈 디렉터리가 되므로 `a/b`가 지워지며, 이어서 `a`도 지워진다. `c` 안에 파일이 있으면 `c`가 빈 디렉터리가 아니므로 `Directory not empty` 오류와 함께 아무것도 지워지지 않는다.

   </details>

4. **less 탐색:** `less /etc/services`로 파일을 연 상태에서 문자열 `TCP`가 있는 곳을 찾고, 다음 검색 결과로 이동한 뒤, `less`를 끝내는 키 입력을 순서대로 쓰라.

   <details>
   <summary>정답</summary>

   `/TCP`를 입력하고 `Enter`를 눌러 앞으로 검색한다. `n`을 눌러 다음 검색 결과로 이동한다. `q`를 눌러 `less`를 끝낸다.

   </details>
