## 연습 문제 1: 파일 유형 식별

**문제:** 다음 `ls -l` 출력에서 `mylink`는 어떤 유형의 파일인가?

```text
lrwxrwxrwx 1 user1 user1 16 Mar 21 10:00 mylink -> /home/user1/data
```

- A. 일반 파일
- B. 디렉터리
- C. 심볼릭 링크
- D. 블록 장치

### 풀이

**정답:** C. 심볼릭 링크

**해설:** `ls -l` 출력의 첫 번째 문자가 파일 유형을 나타낸다. `l`은 심볼릭 링크, `-`는 일반 파일, `d`는 디렉터리, `b`는 블록 장치, `c`는 문자 장치, `p`는 파이프, `s`는 소켓을 의미한다. 이름 뒤의 `->` 화살표도 심볼릭 링크가 가리키는 대상을 보여 준다. 심볼릭 링크의 크기 16은 대상 경로 `/home/user1/data`의 글자 수(16바이트)이다.

## 연습 문제 2: 디렉터리 계층 구조

**문제:** `hostname`, `passwd`, `fstab`과 같은 시스템 전체 설정 파일이 저장되는 디렉터리는?

- A. `/home`
- B. `/var`
- C. `/etc`
- D. `/usr`

### 풀이

**정답:** C. `/etc`

**해설:** `/etc` 디렉터리에는 시스템 전체 설정 파일이 들어 있다. 예를 들어 `/etc/hostname`은 시스템 호스트 이름을, `/etc/passwd`는 사용자 계정 정보를, `/etc/fstab`은 파일 시스템 마운트 항목을 저장한다. `/home`은 사용자 홈 디렉터리를, `/var`는 로그와 같은 가변 데이터를, `/usr`은 기본 실행 파일과 라이브러리 같은 시스템 자원을 저장한다.

## 연습 문제 3: 절대 경로 vs. 상대 경로

**문제:** 현재 작업 디렉터리가 `/home/user1/Documents`일 때, 상대 경로를 사용하여 `/home/user2/file.txt`를 올바르게 참조하는 것은?

- A. `../user2/file.txt`
- B. `./user2/file.txt`
- C. `../../user2/file.txt`
- D. `~/user2/file.txt`

### 풀이

**정답:** C. `../../user2/file.txt`

**해설:** `/home/user1/Documents`에서 시작하여 첫 번째 `..`으로 `/home/user1`로, 두 번째 `..`으로 `/home`으로 올라간 뒤 `user2/file.txt`로 내려가면 `/home/user2/file.txt`가 된다. 선택지 A는 `/home/user1/user2/file.txt`로 해석된다. 선택지 B는 현재 디렉터리 아래를 가리키므로 `/home/user1/Documents/user2/file.txt`가 된다. 선택지 D는 현재 사용자의 홈으로 확장되는 `~`를 사용하므로 상대 경로가 아니며, `/home/user1/user2/file.txt`를 가리킨다.

## 연습 문제 4: 중첩 디렉터리 생성

**문제:** `projects/2025/spring/` 디렉터리 구조를 하나의 명령어로 생성해야 하지만, 상위 디렉터리가 하나도 존재하지 않는다. 어떤 명령어가 성공하는가?

- A. `mkdir projects/2025/spring`
- B. `mkdir -p projects/2025/spring`
- C. `mkdir -r projects/2025/spring`
- D. `rmdir -p projects/2025/spring`

### 풀이

**정답:** B. `mkdir -p projects/2025/spring`

**해설:** `-p`(parents) 옵션은 경로를 따라 필요한 모든 상위 디렉터리를 생성한다. `-p` 없이는 중간 디렉터리가 하나라도 없으면 `mkdir`이 `No such file or directory` 오류로 실패한다. 선택지 C는 `mkdir`에 없는 `-r` 옵션을 사용하므로 `invalid option` 오류가 난다. 선택지 D는 디렉터리를 생성하는 것이 아니라 제거한다.

## 연습 문제 5: 파일 내용 보기

**문제:** 새 항목이 추가되는 로그 파일을 실시간으로 모니터링하고 싶다. 가장 적절한 명령어는?

- A. `cat /var/log/syslog`
- B. `head -f /var/log/syslog`
- C. `tail -f /var/log/syslog`
- D. `less -f /var/log/syslog`

### 풀이

**정답:** C. `tail -f /var/log/syslog`

**해설:** `tail -f`(follow)는 파일의 마지막 10줄을 표시한 뒤, 새로운 줄이 추가될 때마다 계속 감시하며 표시한다. 이는 실시간 로그 모니터링에 매우 유용하다. `cat`은 파일 전체를 한꺼번에 출력하고 끝난다. `head`에는 `-f` 옵션이 없다. `less`의 `-f`는 특수 파일을 강제로 여는 옵션이며, 새로 추가되는 내용을 따라가려면 `less` 안에서 `F` 키를 누르거나 `less +F`로 따로 실행해야 한다.

## 연습 문제 6: 숨김 파일

**문제:** `.`으로 시작하는 숨김 파일을 포함하여 현재 디렉터리의 모든 파일을 나열하려면?

### 풀이

**정답:** `ls -a`

**해설:** `-a`(all) 옵션을 사용하면 `ls`가 이름이 `.`으로 시작하는 숨김 파일과 디렉터리를 포함하여 표시한다. `-a` 없이는 `.bashrc`, `.profile`, `.ssh/`와 같은 파일이 표시되지 않는다. `ls -la`처럼 다른 옵션과 결합하여 숨김 파일을 상세 형식으로 볼 수도 있다. `.`과 `..`을 빼고 보려면 `ls -A`를 쓴다.

## 연습 문제 7: /root와 /의 구분

**문제:** Linux 디렉터리 계층 구조에서 `/`와 `/root`의 차이를 설명하라.

### 풀이

**정답:** `/`는 루트 디렉터리로, 다른 모든 디렉터리가 뻗어 나가는 파일 시스템 계층 구조의 최상위 디렉터리이다. `/root`는 root(슈퍼유저) 계정의 홈 디렉터리로, 보안과 가용성을 위해 `/home/root`가 아닌 `/root`에 위치한다.

**해설:** 일반 사용자의 홈 디렉터리는 `/home/username` 아래에 있지만, root 사용자의 홈은 `/root`이다. 이렇게 분리하면 `/home`이 별도의 파일 시스템이라 마운트되지 않더라도 root가 로그인하여 시스템을 복구할 수 있다. 두 디렉터리는 root라는 이름을 공유하지만 완전히 다른 디렉터리이다.

## 연습 문제 8: ls -l 출력 해석

**문제:** 다음 출력에서 `report.txt` 파일의 하드 링크 수와 파일 크기는?

```text
-rw-r--r-- 3 user1 staff 2048 Mar 21 14:00 report.txt
```

### 풀이

**정답:** 이 파일은 3개의 하드 링크를 가지며, 크기는 2048바이트이다.

**해설:** `ls -l` 출력에서 권한 문자열 바로 다음의 숫자가 하드 링크 수(이 경우 3)이다. 소유자와 그룹 다음, 날짜 앞의 숫자가 바이트 단위의 파일 크기(2048)이다. 하드 링크 수 3은 같은 inode를 가리키는 디렉터리 항목(파일 이름)이 3개 있음을 의미한다.
